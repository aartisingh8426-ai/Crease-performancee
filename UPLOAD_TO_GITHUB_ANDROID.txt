CREASE PERFORMANCE — ANDROID PROJECT

This ZIP contains the Android Studio project and its GitHub Actions APK build workflow.

UPLOAD FROM ANDROID:
1. Extract this ZIP.
2. Open the folder containing settings.gradle and app/.
3. Upload the CONTENTS of that folder to the ROOT of your GitHub repository.
4. Preserve folder paths. Do not upload only the app/src/main/assets files.
5. Make sure the hidden .github folder is included. It must contain:
   .github/workflows/build-apk.yml
6. Commit the files to the repository's default branch.
7. Open GitHub > Actions and select the Android APK build workflow.
8. Run the workflow. After it succeeds, open the run and download the APK from Artifacts.

This is project source code, not a precompiled APK. GitHub Actions or Android Studio must build it.
